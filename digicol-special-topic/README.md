# 故宫古文字数字平台专题页：前端仿制练习

## 文件
- `index.html`：页面结构与文案
- `styles.css`：颜色、布局、响应式样式与 CSS 示意图
- `app.js`：筛选、搜索、详情弹窗、移动端导航

## 在 VS Code 中运行
1. 解压文件夹并用 VS Code 打开。
2. 安装 VS Code 扩展 `Live Server`（可选）。
3. 右键 `index.html`，选择 `Open with Live Server`；也可以直接双击打开。
4. 页面字体会尝试从 Google Fonts 加载；无法联网时使用系统字体回退。

## 重要说明
这是依据公开页面信息制作的独立前端示例，并非故宫博物院官方代码，也不是逐像素复制。专题原站在自动访问时未能完整加载，因此文物卡片使用 CSS 绘制的示意图，内容也是说明性占位文案。若要达到高保真复刻，需要在浏览器中手动检查原站的实际布局，并使用有权使用的真实图片、字体、图标和公开接口数据。

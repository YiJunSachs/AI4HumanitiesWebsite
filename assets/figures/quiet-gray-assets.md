# Quiet gray redesign assets

- `contour-divider-a.png` and `contour-divider-b.png`: original AI-generated transparent contour-landscape separators, created 2026-10-29 from the user's style references. Reference sheets and watermarks are not distributed.
- `cclass-emblem-cutout.png`: transparent exterior cutout of the existing CCLASS institutional shield supplied in this repository; retained lettering and shield content.
- `zhishan-soft-gray-header.svg`: code-authored smooth curves and muted gray-green field, reusing the existing Lanting JPEG embedded in `zhishan-lanting-header.svg`. Historical source attribution remains in `lanting-source.json`.
- `team-flow-boundary.svg`: code-authored smooth rising lower boundary.
- Palette: #f0efeb, #e7e6e2, #dedbd5, #d4d0c9, derived as four adjacent light warm-gray values from the user's traditional gray color sheet.
- Formal handwriting font: Kalam Regular, from https://github.com/google/fonts/tree/main/ofl/kalam; the font and OFL license are in `assets/fonts/team/`.
